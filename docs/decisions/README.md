# Decisions

Each file here is one decision record: what was decided, when, and why.

| Record | Subject | Status |
|---|---|---|
| [0001](0001-pre-prd-product-decisions.md) | Decisions made before the requirements were written | Accepted |
| [0002](0002-stack-a-review-clarifications.md) | Clarifications from the Stack A review | Accepted |

## Rules

- The newest record wins. Where an older record says something different, the newer one supersedes it.
- To change a decision, add a new record. Do not rewrite an old one.
- Every decision has an ID of the form `DEC-001`. Requirement documents cite these IDs, and the documentation check verifies that every cited ID exists.
